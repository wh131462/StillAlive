# 「仍在」V4 改造计划与勾选清单

> 用途：把当前产品的改造点拆成可勾选的功能项，便于做范围和优先级取舍。
> 基准：当前工作区 v1.1.20 源码。V4 设计稿只作为交互参考，不是生产实现方案。
> 成本：单位为人日，含约 20% 双端回归缓冲。实际排期按真机验证结果调整。
> 原则：不做排行榜、积分、断签惩罚、社交比较、AI 情绪分析。

## 0. 勾选方式

- 要做的项，把 `- [ ]` 改成 `- [x]`。
- 想调整范围，直接在行尾加备注，例如 `> 本期不做`、`> 拆成两步`。
- 标记说明：`必做` 是承诺与数据问题；`建议` 是体验收益高；`可选` 是锦上添花；`待决策` 需要产品先定。
- 推荐先勾 A 包，再按人力和发布窗口决定 B、C 包。

## 1. 总览

| 包 | 内容 | 项数 | 预估 | 建议 |
|---|---|---:|---:|---|
| A | 信任修复：数据、安全、文案与可用性 | 13 | 13.2 人日 | 必做为主，A13 可选 |
| B | 回应系统：保存、打卡、主题、备份的完成感 | 8 | 11.0 人日 | 建议紧随 A |
| C | 时间回声：回忆、日历回声、生日 | 4 | 6.0 人日 | 产品差异化核心 |
| D | 人物生长：计数、相册、档案建议、关系树 | 4 | 7.5 人日 | 第二阶段 |
| E | 媒体与安全：阅读、摘抄、音乐、密码、备份 | 9 | 14.0 人日 | 按深度需求排 |
| F | 可选仪式：年度回顾、今日一签、启动个性化 | 3 | 5.5 人日 | 传播版本再做 |

**推荐起步包：A1 到 A12 + B1/B3/B4/B5/B8，约 18 人日。** 全选约 57.2 人日，仅用于对比，不建议一次做完。
理由：先把“说得到做不到”修掉，再让核心动作有回执；C 包紧随其后，不和大规模数据库迁移放在同一发布。

快速选择：

- [ ] 采用推荐起步包：A1 到 A12 + B1/B3/B4/B5/B8（约 18 人日）
- [ ] 只做最小信任包：A1 到 A12（约 10.7 人日，不含 B 包回应系统）

## 2. A 包：信任修复

### A1 书摘保留

- [x] **A1 书摘保留**（2.5 人日，必做）
  - 做什么：删除书籍时不再级联删除摘抄；摘抄保存书名快照；旧备份恢复后仍可读。
  - 验收：删书后摘抄仍在，空间里的读书笔记仍能显示原书名，并标记“原书已删除”。
  - 风险：SQLite 迁移与旧备份兼容，需要单独回归。

### A2 密码本安全动作

- [ ] **A2 密码剪贴板清理与显示超时**（1.5 人日，必做）
  - 做什么：复制密码后 60 秒读回校验，仍是本次密码才清空；密码明文显示 8 秒后自动隐藏。
  - 验收：复制后 60 秒剪贴板清空；切到别的 App 再回来，密码已隐藏；复制失败有提示。
  - 风险：系统剪贴板读取权限与后台计时，需要 iOS/Android 真机验证。

### A3 备份语义

- [x] **A3 备份记账与文案**（0.5 人日，必做）
  - 做什么：系统分享面板无法确认“已保存”，把“上次导出”改成“上次生成”；成功回执写清楚文件已生成、等待用户选择保存位置。
  - 验收：用户取消分享时，界面不声称“备份已完成”。
  - 风险：平台能力限制，文案必须诚实。

### A4 更新下载

- [x] **A4 更新“继续下载”语义**（0.5 人日，必做）
  - 做什么：当前错误态“继续下载”实际从头开始，先改成“重新下载”；续传单独评估。
  - 验收：按钮文案与真实行为一致。
  - 风险：若后续做续传，需要下载器支持 Range。

### A5 PDF 摘抄文案

- [x] **A5 PDF 摘抄高亮门控**（0.3 人日，必做）
  - 做什么：PDF 内核不具备高亮能力时，不再显示“保存后会恢复高亮”，改为“保存为摘抄，高亮仅 EPUB 支持”。
  - 验收：PDF 选区摘抄和手动摘抄的提示与实际能力一致。
  - 风险：需要区分 EPUB 与 PDF 的 manual 分支。

### A6 编辑器媒体替换

- [x] **A6 编辑器媒体替换可点击**（0.5 人日，必做）
  - 做什么：失败态写“轻触替换”时，点击图片本体也能触发替换；或把文案改成实际可用的操作。
  - 验收：编辑器中点击失败媒体能看到替换入口。
  - 风险：与视频点击、文本选区的误触冲突。

### A7 评论入口与删除

- [x] **A7 评论入口与删除确认**（0.5 人日，必做）
  - 做什么：修正正文下方“更多记录操作”的无障碍命名；评论删除增加确认；评论入口改成可发现的“写一句”。
  - 验收：读屏能区分记录菜单和评论；删除评论有二次确认。
  - 风险：入口改动会影响首页和详情页两处布局。

### A8 人物列表

- [x] **A8 人物排序、首帧与计数**（1.0 人日，必做）
  - 做什么：排序改用真实最近记录时间，不再被置顶污染；摘要未就绪时显示占位而不是跳序；行内显示“共同记录 N 条、最近一天”。
  - 验收：首帧不抖动；置顶旧记录不会把人物顶到最前；列表能看到计数。
  - 风险：需要补一条聚合查询或复用现有 `getPostsByPerson`。

### A9 日历写一条

- [ ] **A9 日历“写一条”不静默重定向**（0.5 人日，待决策）
  - 做什么：今天未打卡时，不再无提示送回首页。二选一：允许直接进编辑器，或把按钮改成“先打卡”并说明原因。
  - 验收：用户知道为什么被带回首页，或者能直接写。
  - 风险：改变“打卡后才能写当天记录”的现有规则，需要产品确认。

### A10 小修集合

- [x] **A10 小修集合**（0.9 人日，必做）
  - 做什么：夜墨主题热力图未来格去掉硬编码白色；人物编辑重复“03”改为“05”；忘记密码删除密码本增加二次确认；个人资料返回前增加未保存提示。
  - 验收：夜墨无白块；编辑页节号连续；两条删除路径强度一致；资料页误返回不会静默丢失。
  - 风险：个人资料脏检查涉及页面返回拦截。

### A11 对比度

- [x] **A11 对比度修正**（1.5 人日，必做）
  - 做什么：`sun` 不再用于正文级文本，改用深金 `goldInk`；浅色主题 `inkFaint` 加深到 4.5:1 以上；检查 8–10px 元信息的可读性。
  - 验收：三套主题下正文与关键元信息达到 WCAG AA；夜墨无低对比文本。
  - 风险：涉及 `packages/tokens` 与多处样式，需要逐屏回归。

### A12 触控尺寸

- [x] **A12 触控区 44pt**（0.5 人日，必做）
  - 做什么：月份箭头、写一条、顶栏文字按钮、媒体替换/删除、评论入口统一到 44px；密集日历和点阵保留例外。
  - 验收：主操作可稳定点中，误触下降。
  - 风险：紧凑布局可能需要 4–8px 的高度重排。

### A13 邀请链接可重取

- [x] **A13 邀请链接可重取**（2.5 人日，建议）
  - 做什么：邀请请求持久化，人物页显示“待回信 / 剩余天数”，支持复制或重发；分享取消不删除请求。
  - 验收：关闭分享面板后仍能再次取得同一链接；过期或已导入有明确状态。
  - 风险：需要新增列表查询与清理逻辑，但不进入备份。

## 3. B 包：回应系统

- [x] **B1 统一轻提示**（1.5 人日，建议）
  - 做什么：在 `shared/feedback.ts` 增加 `notice` 类型，由现有 FeedbackProvider 渲染非阻塞 toast；成功类消息不再用 alert。
  - 验收：保存、备份、采纳等成功动作有轻提示；错误仍用明确的对话框。
  - 风险：需要区分 notice 与 error，避免把破坏性操作做成一闪而过。

- [x] **B2 轻触觉**（1.5 人日，待决策）
  - 做什么：引入 `expo-haptics`，只给打卡、保存、建关系、采纳印象 4 个时刻；提供全局开关。
  - 验收：4 个时刻有轻触觉；关闭后完全静音；低端 Android 不掉帧。
  - 风险：新增原生依赖，需要重新构建；如果本期只能 OTA，先延后。

- [x] **B3 编辑器保存回执与草稿状态**（2.0 人日，建议）
  - 做什么：完成前显示“已记下 21:12”，再退栈；草稿状态加时间戳、失败可重试、2 秒后回落引导语。
  - 验收：保存有明确完成感；草稿状态不永久占用标题；保存后草稿不复活。
  - 风险：与现有 450ms 草稿队列的竞态需要回归。

- [ ] **B4 打卡仪式**（1.5 人日，建议）
  - 做什么：坐标点落位、卡片完成态、首页标题与计数联动；不新增连续天数。
  - 验收：打卡后 240ms 内有可见变化；计数同步；无庆祝粒子。
  - 风险：低端 Android 的动画掉帧，需要限幅到 transform/opacity。

- [x] **B5 主题过渡**（1.0 人日，建议）
  - 做什么：点击主题先乐观更新，120ms 纸色遮罩淡出，失败回滚；消除等待写库的空窗。
  - 验收：切换主题即时响应；三套主题来回切换不闪烁。
  - 风险：多屏同时重绘的性能。

- [x] **B6 备份回执与阶段进度**（1.5 人日，建议）
  - 做什么：生成中显示“快照 / 打包 / 分享”三阶段；成功后给文件名、大小、条数；取消分享不记账。
  - 验收：备份过程可见；成功有回执；取消不会伪装成成功。
  - 风险：需要归档层回传进度。

- [x] **B7 音乐队列语义**（1.0 人日，建议）
  - 做什么：行播放使用当前可见列表；“随机播放”只本次生效，不改持久模式；播放中同曲恢复；队列打开定位当前曲。
  - 验收：搜索后播放的队列与看到的一致；随机不会影响下一次“播放全部”。
  - 风险：需要统一多个入口的队列构造。

- [x] **B8 新记录入场与定位**（1.0 人日，建议）
  - 做什么：保存后新记录在时间线顶部插入并短暂高亮，页面滚到该条。
  - 验收：从编辑器返回能立刻看到刚写的记录。
  - 风险：虚拟列表插入后的滚动定位。

## 4. C 包：时间回声

- [ ] **C1 记忆追踪点阵**（1.5 人日，建议）
  - 做什么：把四个静态数字改成 30 天点阵，点格跳日历；保留累计天数和坐标数。
  - 验收：点格能回到对应日期；空数据有合适文案。
  - 风险：密集点阵的触控尺寸，需要控制格子数量。

- [x] **C2 日历回声**（1.5 人日，建议）
  - 做什么：选中日期时，追加最多一条“X 年前的今天”，无内容不占位。
  - 验收：2026.07.20 能看到 2025.07.20 的记录；没有回声时不出现空块。
  - 风险：按 `MM-DD` 匹配要处理农历生日与闰年差异。

- [x] **C3 首页回忆单卡轮换**（1.5 人日，待决策）
  - 做什么：保持 PRD 的“一次最多一张回忆”，按优先级轮换那年今日、人物回忆、书摘；备份提醒不再挤掉回忆。
  - 验收：首页每次只有一张主回忆；备份提醒在其后出现。
  - 风险：如果要做三卡横滑，需要改 PRD 与信息架构。

- [ ] **C4 生日横幅**（1.5 人日，建议）
  - 做什么：人物详情显示“还有 3 天 / 第 27 个生日”；生日当天聚合历年同日记录。
  - 验收：生日前后文案正确；农历生日换算正确。
  - 风险：农历与 `dayKey` 的换算需要测试。

## 5. D 包：人物生长

- [x] **D1 人物列表计数**（1.0 人日，建议）
  - 做什么：显示共同记录数、最近一天、生日倒计时；排序依据可见。
  - 验收：列表信息与人物详情一致。
  - 风险：每人一次查询，人数多时需要聚合。

- [ ] **D2 人物相册按月**（2.5 人日，建议）
  - 做什么：按月分组，顶部加“那年这个月”；支持多选批量移除/设封面。
  - 验收：照片按拍摄或导入时间分组；批量操作有确认。
  - 风险：媒体时间戳缺失时需要回退策略。

- [x] **D3 档案建议采纳**（2.0 人日，待决策）
  - 做什么：从最近记录中手动选一句，采纳为人物印象；不自动改写，不做 AI 抽取。
  - 验收：采纳前可预览，采纳后只更新一句，取消不写入。
  - 风险：需要新增选句交互；如果要在 WebView 正文中选句，成本可能高于 2 人日。

- [x] **D4 关系树聚焦**（2.0 人日，建议）
  - 做什么：选中节点描边放大，相关边高亮；缩放低于 0.45 时隐藏关系标签，只留头像和姓名。
  - 验收：节点多时仍能看清当前人物；缩放后不出现不可读文字。
  - 风险：节点动画并发与性能。

## 6. E 包：媒体与安全

- [x] **E1 阅读器控制层避让**（1.0 人日，建议）
  - 做什么：控制层展开时不遮挡正文首尾；修正上下安全区计算。
  - 验收：控制层出现时正文不被盖住。
  - 风险：EPUB 与 PDF 的正文边距不同。

- [x] **E2 EPUB 点击翻页**（1.5 人日，待决策）
  - 做什么：恢复左右点击翻页区，中间区域留给文本选区和控制层；PDF 保持原生手势。
  - 验收：EPUB 可点击左右翻页；长按选择不误触。
  - 风险：与文本选区、链接点击冲突。

- [x] **E3 全局摘抄页**（3.0 人日，可选）
  - 做什么：新增按书分组的摘抄列表，支持搜索和回跳原文；分享卡可回到具体摘抄。
  - 验收：摘抄能独立找到；回跳定位有偏差时有提示。
  - 风险：CFI 在重排或换版后可能失效。

- [x] **E4 阅读默认设置**（1.5 人日，可选）
  - 做什么：字号、行距、主题支持“设为所有书默认”，书级偏好覆盖全局默认。
  - 验收：换书不重复调四项设置；旧书偏好保留。
  - 风险：旧 JSON 兼容与迁移。

- [x] **E5 备份恢复差异**（2.0 人日，建议）
  - 做什么：恢复前展示当前与备份的条数、媒体数、导出时间；提供“先导出一份再恢复”。
  - 验收：覆盖前能核对差异；破坏性操作有二次确认。
  - 风险：合并模式的差异难以精确预览。

- [ ] **E6 密码锁定宽限**（2.0 人日，待决策）
  - 做什么：可选 30/60 秒宽限，默认仍为立即锁定；切回前台按计时决定是否重新解锁。
  - 验收：默认安全模型不变；开启宽限后不反复解锁。
  - 风险：弱化安全承诺，需要产品与安全评审。

- [ ] **E7 更新跳过版本**（1.0 人日，可选）
  - 做什么：记住跳过的版本号，下次启动不再提示；有新版本时恢复提示。
  - 验收：跳过生效；卸载重装后不保留。
  - 风险：需要新增偏好字段。

- [x] **E8 音乐进度拖拽**（1.5 人日，可选）
  - 做什么：进度条支持拖动 seek，保留点击 seek；补充无障碍 adjustable 动作。
  - 验收：拖动跟手；松手后位置正确。
  - 风险：与播放器手势、悬浮层冲突。

- [x] **E9 悬浮播放器遮挡**（0.5 人日，建议）
  - 做什么：统一为所有列表补底部留白，避免收起态播放器盖住最后一行。
  - 验收：首页、书架、详情页最后一条不被遮挡。
  - 风险：需要逐页检查。

## 7. F 包：可选仪式

- [ ] **F1 年度坐标图**（3.0 人日，可选）
  - 做什么：用确定性数据生成年度海报：打卡点阵、城市、书、音乐、人物；不做 AI 总结和评分。
  - 验收：可保存长图；数据只来自本地。
  - 风险：长图渲染性能与中文字体。

- [ ] **F2 今日一签**（1.5 人日，可选）
  - 做什么：黄历宜忌 + 当天记录 + 一张可保存的签卡；不做运势预测。
  - 验收：文案温和；可保存；不产生每日强制提醒。
  - 风险：容易被误解为玄学功能，需要克制。
