# still-alive.com 产品设计文档

> 那些差点就没了，但我现在还活着的瞬间。

---

## 1. 产品概述

### 1.1 一句话定位

still-alive.com 是一个非营利的匿名故事收集站。主题只有一个：**生命的韧性**。

这里收录那些"差点就没了，但我现在还活着"的瞬间——车祸后打开的日记本、大病初愈时第一口食物的味道、走出抑郁后在阳台看到的那场日出。

### 1.2 产品哲学

| 原则 | 说明 |
|------|------|
| **不贩卖焦虑** | 关注"活下来之后"，而非死亡本身 |
| **只陈列韧性** | 每一则故事都是一个"仍在"的证明 |
| **集体回忆录** | 像一本持续书写的书，每个人都是其中一页 |
| **设计退场** | 界面退到背后，让文字成为唯一主角 |

### 1.3 与「还活着」App 的关系

| 维度 | 还活着 App | still-alive.com |
|------|------------|-----------------|
| 性质 | 私人工具 | 公共空间 |
| 用户行为 | 每日打卡、记录生活 | 投稿故事、阅读共鸣 |
| 时间尺度 | 日常、持续 | 片段、永久 |
| 关系 | 个人的生存确认 | 集体的生存见证 |

两者共享品牌理念与设计语言，互相独立运营。App 是私人日记，网站是公共展览。

### 1.4 非营利声明

- 无广告
- 无付费内容
- 无数据售卖
- 服务器费用由团队自筹或接受透明捐赠

## 2. 内容规范

### 2.1 故事方向

这里不需要宏大叙事，一个细节、一个瞬间即可：

**意外与事故**
> "车祸后，我在路边蹲了很久。不是因为腿软，是因为发现路边有株野花在开。"

**疾病与康复**
> "化疗的最后一天，护士问我出院想吃什么。我说想吃泡面，她笑了。那碗面是我吃过最好吃的东西。"

**心理与精神**
> "那天早上，我没有按计划执行。我去开了窗，发现楼下有人在遛狗。那条狗太蠢了，它在追一片叶子。"

**自然与极限**
> "被救上船的时候，我一直盯着手心。我想把那个颜色记住。那是我第一次觉得皮肤的颜色很好看。"

### 2.2 内容调性

- 重点在**"活下来之后"**，而非死亡经过
- 温情而非猎奇，诗意而非渲染
- 鼓励细节、感官、具体——不鼓励说教或总结

### 2.3 审核标准

| 通过 ✓ | 拒绝 ✗ |
|--------|--------|
| 聚焦于存活后的感受与细节 | 详述死亡手段（尤其自杀方法） |
| 第一人称真实叙述 | 虚构或明显捏造的故事 |
| 匿名或化名保护隐私 | 含真实姓名、可识别地点信息 |
| 温暖 / 诗意 / 平静 / 幽默的语气 | 仇恨、歧视或攻击性内容 |
| 不确定性、困惑、甚至黑色幽默 | 以他人苦难为乐的叙述 |

## 3. 功能规范

### 3.1 页面结构

```
still-alive.com
│
├── /              首页（故事流）
├── /submit        投稿页
├── /story/:id     故事详情页
├── /random        随机故事
├── /about         关于页
└── /admin         管理后台（隐藏入口）
```

### 3.2 首页（故事流）

**信息层级**

```
┌─────────────────────────────────────────┐
│  still-alive                        投稿 │  ← 极简顶栏
├─────────────────────────────────────────┤
│                                         │
│  [故事标题或首句]                        │  ← 故事卡片
│                                         │
│  正文预览（约3行）                       │
│  …展开阅读                              │
│                                         │
│  2019 年夏天    ♡ 143 人感同身受         │  ← 元信息行
├─────────────────────────────────────────┤
│  [下一则故事]                            │
│  ...                                    │
└─────────────────────────────────────────┘
```

**交互规则**
- 无分页，平滑滚动加载（每次加载 10 则）
- 点击故事卡片展开全文（无需跳页，原地展开）
- 只有两个动作：**共鸣** 和 **分享**
- 顶部提供分类筛选（默认"全部"）

### 3.3 投稿页

**表单字段**

| 字段 | 是否必填 | 限制 |
|------|----------|------|
| 正文 | 必填 | 100–800 字 |
| 标题 / 开头第一句 | 选填 | ≤ 30 字 |
| 大致时间 | 选填 | 自由文本，如"2019 年夏天" |
| 故事类型 | 选填 | 单选，见 §3.5 |
| 联系邮箱 | 选填 | 仅用于审核结果通知 |

**提交后**
- 提示语："已收到，我们会在 48 小时内审核。感谢你愿意把这一刻分享出来。"
- 无账户体系，无法追踪投稿状态（有邮箱则邮件通知）

### 3.4 故事详情页

- 全屏沉浸式阅读，最大宽度 640px，居中
- 顶部：返回按钮（← 回到所有故事）
- 底部：共鸣按钮 + 分享按钮 + 心理健康提示（若涉及敏感话题）
- 无评论区（保持安静）

### 3.5 随机故事

- URL：`/random`，每次访问随机跳转到一则已发布故事
- 底部仅有两个按钮："下一则" 和 "回到首页"
- 适合作为收藏/分享链接

### 3.6 关于页

- 产品理念（3 段，不超过 300 字）
- 投稿指南
- 心理援助资源
- 联系方式（邮箱）
- 当前收录故事数（实时统计）

### 3.7 交互细节

#### 共鸣（替代"点赞"）

- 图标：心跳波形（SVG 动画，与 App 心跳动画同源）
- 文案：**"共鸣"** 或 **"我也是"**，不用"赞"
- 无需登录；基于浏览器 localStorage 防止重复点击
- 触发后：图标轻跳一次（同 App heartbeat 动画，150ms）
- 显示格式：`♡ 143 人感同身受`

#### 内容警告

- 涉及自杀、暴力的故事在展开前显示：
  ```
  这则故事涉及敏感内容，请在准备好的时候继续阅读。
  [继续阅读]
  ```
- 一次确认即可，不重复弹出

#### 分享

- 复制纯文字（无追踪参数）
- 生成分享图片（深色背景 + 白色文字卡片，适合朋友圈）
- 分享入口低调处理，不强制

## 4. 设计规范

> 本节在「还活着」App 设计规范（[DESIGN_SPEC.md](./DESIGN_SPEC.md)）基础上扩展，以下为差异项与补充项。

### 4.1 整体风格原则

| 原则 | 实现方式 |
|------|----------|
| **文字即界面** | 排版是唯一装饰，禁止多余图形元素 |
| **呼吸与静默** | 行高 1.8，段间距充足，大量空白 |
| **单列叙事** | 内容区始终居中单列，`max-width: 640px` |
| **颜色极度克制** | 全站不超过 3 种颜色，主色仅用于关键操作 |

### 4.2 色彩（沿用 App 规范，更克制）

```css
:root {
  /* 网站版本使用更柔和的基调 */
  --color-bg: #fafafa;          /* 近白，比纯白更柔 */
  --color-text: #1e293b;        /* 主文字 */
  --color-text-muted: #94a3b8;  /* 时间戳、标签等静默信息 */
  --color-border: #f1f5f9;      /* 极淡分割线 */
  --color-primary: #10b981;     /* 仅用于共鸣计数和 CTA */
  --color-accent: #f43f5e;      /* 心跳图标 */
}

[data-theme="dark"] {
  --color-bg: #0f172a;
  --color-text: #f1f5f9;
  --color-text-muted: #475569;
  --color-border: #1e293b;
  --color-primary: #34d399;
  --color-accent: #fb7185;
}
```

### 4.3 字体（网站特供）

故事正文使用衬线字体，强调"阅读"而非"浏览"：

```css
/* 故事正文 */
--font-story: "Noto Serif SC", "Source Han Serif SC", Georgia, serif;

/* 界面文字（标签、按钮、时间戳） */
--font-sans: -apple-system, "Noto Sans SC", sans-serif;

/* 数字（共鸣数） */
--font-mono: "SF Mono", Monaco, monospace;
```

### 4.4 字号规范（网站版）

| 用途 | 字号 | 行高 | 字重 |
|------|------|------|------|
| 故事正文 | 18px | 1.8 | 400 |
| 故事标题 / 首句 | 20px | 1.4 | 500 |
| 站点名称 | 24px | 1.2 | 300 |
| 时间戳 / 分类标签 | 13px | 1.4 | 400 |
| 按钮文字 | 14px | 1.4 | 500 |

### 4.5 特色动画

**心跳线（页面装饰）**
- 页面顶部有一条极细（1px）的心跳波形 SVG 作为装饰
- 默认静止，滚动到顶部时触发一次动画
- 颜色使用 `--color-accent`（心跳红），透明度 30%

**共鸣反馈**
- 点击后图标执行 `heartbeat` 动画一次（借用 App 规范中的 `@keyframes heartbeat`）
- 数字用 `counting-up` 动画从旧值跳到新值

**故事展开**
- 原地展开全文，使用 `height` + `opacity` 过渡，300ms
- 不跳页，不打断阅读流

**页面进入**
- Fade in，200ms，无其他变换

### 4.6 响应式

| 断点 | 最大内容宽 | 边距 |
|------|------------|------|
| mobile (< 640px) | 100% | 20px |
| tablet (640–1024px) | 640px | auto |
| desktop (> 1024px) | 640px | auto |

故事内容永远不超过 640px，确保舒适的阅读行长。

## 5. 内容安全

### 5.1 心理健康提示

所有涉及抑郁、自杀的故事，文末自动附加：

```
如果你正在经历类似的时刻，请联系：
北京心理危机研究与干预中心：010-82951332
全国心理援助热线：400-161-9995
```

措辞克制，不说教，不反复出现。

### 5.2 审核流程

```
投稿 → 进入待审队列
           │
      48h 内审核
      ┌────┴────┐
   通过          拒绝
     │             │
  自动发布     (可选)邮件说明原因
```

### 5.3 隐私保护

- 不收集 IP 地址（或收集后立即哈希）
- 不使用第三方统计工具（如 Google Analytics）
- 投稿邮箱仅用于通知，不与故事内容关联存储

## 6. 技术规范

### 6.1 架构原则

- **静态优先**：已审核故事预渲染为静态页，首屏无 JS 依赖
- **无账户体系**：读者无需注册，投稿者无需注册
- **最小追踪**：不依赖第三方 Cookie 或分析脚本

### 6.2 推荐技术栈

| 层次 | 选型 | 说明 |
|------|------|------|
| 前端框架 | Next.js 15（App Router） | SSG + ISR |
| 样式 | Tailwind CSS | 沿用 App 规范 |
| 数据库 | Supabase（PostgreSQL） | 故事存储与审核状态 |
| 部署 | Vercel | 边缘节点加速 |
| 邮件通知 | Resend | 审核结果通知投稿者 |
| 图片生成 | @vercel/og | 分享图片生成 |

### 6.3 数据模型

```typescript
interface Story {
  id: string;
  title?: string;           // 选填，≤ 30 字
  content: string;          // 100–800 字
  approximate_date?: string; // "2019 年夏天"（自由文本）
  category?: StoryCategory;
  has_sensitive_content: boolean; // 是否需要内容警告
  resonance_count: number;
  created_at: Date;
  published_at?: Date;
  status: 'pending' | 'approved' | 'rejected';
  // 不存储 IP 或邮箱（邮箱单独记录，不与故事关联）
}

type StoryCategory =
  | 'accident'  // 意外与事故
  | 'illness'   // 疾病与康复
  | 'mental'    // 心理与精神
  | 'nature'    // 自然与极限
  | 'other';    // 其他
```

### 6.4 性能目标

| 指标 | 目标 |
|------|------|
| LCP | < 1.5s |
| CLS | < 0.1 |
| 首页 JS 体积 | < 50kb（gzip） |
| 无 JavaScript 时 | 内容仍可阅读（纯 HTML） |

## 8. 运营规范

### 8.1 故事数量节奏

- 上线初期：手动筛选 20–30 则高质量种子故事
- 维持频率：每周至少发布 3 则新故事
- 不追求数量，拒绝水化内容

### 8.2 文案调性

整体文案延续「还活着」App 的风格——温和、有黑色幽默感、非说教：

| 场景 | 文案 |
|------|------|
| 首页标题 | "那些差点就没了，但我现在还活着的瞬间" |
| 投稿引导 | "你有这样的瞬间吗？写下来，这里接住它。" |
| 提交成功 | "已收到。感谢你把这一刻分享给我们。" |
| 空状态 | "正在等待第一则故事。" |
| 共鸣按钮 | "我也是" / "感同身受" |
| 404 页面 | "这一页不见了，但你还在。" |

### 8.3 捐赠（可选）

若接受捐赠维持服务器运营：
- 公开资金使用情况
- 不因捐赠改变内容方向
- 捐赠入口低调处理，不打扰阅读体验
