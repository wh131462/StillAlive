Design Notes
01 · QUIET START

先留下坐标

今日页只有一个主动作。完成之前不暴露输入框，完成之后才温和邀请记录。

02 · NO STREAK

没有断签压力

展示累计坐标而非连续天数。没有补签、红色警告、积分或失败状态。

03 · MEMORY RETURN

让过去回来

往日回忆与时间线是核心，不把产品做成只负责收集内容的空仓库。
