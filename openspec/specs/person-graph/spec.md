## Requirements
### Requirement: 人物 tab 默认进入关系图

人物 tab SHALL 默认显示「以我为中心的关系图」视图；列表视图作为副视图，通过顶部分段控件切换。

#### Scenario: 默认视图

- **WHEN** 用户首次进入「人物」tab
- **THEN** 主区域呈现关系图，列表入口在顶部分段控件的副位
- **AND** 用户上次切换的视图偏好被本地记住，下次按偏好打开

#### Scenario: 切换视图

- **WHEN** 用户在「人物」tab 顶部点击「列表」分段
- **THEN** 主区域切换到列表视图（沿用已有人物列表样式）
- **AND** 切换无跳页动效，平滑切换 200ms

### Requirement: 关系图以"我"为固定中心

关系图 SHALL 固定将「我」节点放在画布中心，其它人物以同心圆 / 力布局散布。

#### Scenario: 中心节点固定

- **WHEN** 渲染关系图
- **THEN** 「我」节点（头像 + 「我」字样）出现在画布几何中心
- **AND** 即使用户拖动其它节点，「我」节点位置不变（被钉住）
- **AND** 缩放与画布平移不改变「我」相对于画布的位置

#### Scenario: 节点呈现

- **WHEN** 渲染每个非"我"人物
- **THEN** 节点为头像圆形 + 下方人物名（最多 5 字，超出省略）
- **AND** 节点直径 56px（移动端 48px）
- **AND** 节点底色由该人物的 `themeColor` 决定（无主题色时用 surface-2）

#### Scenario: 边渲染

- **WHEN** 两个节点之间存在 `relation`
- **THEN** 画一条细线连接两者（1.5px / `--ink-faint`）
- **AND** 线段中点显示关系类型小标签（"妈妈" / "高中同学" 等，mono 10px）
- **AND** 双向关系仅画一条线（不画双箭头）

### Requirement: 关系类型自由度

系统 SHALL 在新增 / 编辑 relation 时同时提供「常见预设」和「自定义」两种关系类型来源。

#### Scenario: 预设关系

- **WHEN** 用户为某人添加关系
- **THEN** 弹出关系类型选择面板，预设至少包含：
  - 家人：爸爸 / 妈妈 / 儿子 / 女儿 / 兄弟 / 姐妹 / 伴侣 / 爷爷 / 奶奶 / 外公 / 外婆 / 叔叔 / 姑姑 / 舅舅 / 阿姨
  - 社会：朋友 / 同学 / 老师 / 同事 / 邻居 / 室友 / 恋人 / 前任
- **AND** 预设按场景分组（家人 / 社会），每组横向滚动可见

#### Scenario: 自定义关系

- **WHEN** 用户在预设之外需要其它关系类型
- **THEN** 面板底部提供「自定义」入口，弹出输入框（最长 8 字）
- **AND** 自定义类型加入本地词典，下次出现在「自定义」分组中
- **AND** 自定义类型可在「设置 → 关系类型管理」中重命名 / 删除

#### Scenario: 人物之间互连

- **WHEN** 用户在关系图中长按某人物节点 → 拖动到另一人物节点
- **THEN** 弹出关系类型面板，建立两人之间的关系（不经过"我"）
- **AND** 边以同样的视觉呈现，关系标签位于中点

### Requirement: 缩放与拖动

关系图 MUST 支持画布缩放、平移和非中心节点拖动，并在本地保存节点位置。

#### Scenario: 双指缩放（移动端）

- **WHEN** 用户在画布两指捏合 / 展开
- **THEN** 画布在 0.5x ~ 2.5x 之间缩放
- **AND** 「我」节点位置保持中心不变（缩放以「我」为锚点）

#### Scenario: 拖动单节点

- **WHEN** 用户长按非"我"节点 0.4 秒后拖动
- **THEN** 该节点跟随手指移动，松手后位置被记住（写入本地 layout 配置）
- **AND** 双指拖动画布则平移整张图

### Requirement: 点击节点进详情

关系图 MUST 根据被点击节点跳转到对应人物详情或「我的」页面。

#### Scenario: 进入详情

- **WHEN** 用户单击任一非"我"节点
- **THEN** 跳转到该人物的 `person-detail-v2` 屏
- **AND** 跳转动效采用 sheet 上拉（移动端）或居中浮层（桌面端）

#### Scenario: 点击"我"节点

- **WHEN** 用户单击中心的「我」节点
- **THEN** 跳转到「我的」tab 而非进入人物详情
